# Demonstração

Esta seção apresenta a aplicação em funcionamento utilizando exclusivamente
dados fictícios preparados para o case.

O vídeo abaixo oferece uma visão rápida da V1 antes do aprofundamento nos
fluxos técnicos específicos.

A demonstração percorre os principais pontos disponíveis atualmente:

* login no contexto do tenant;
* estrutura e navegação da aplicação;
* clientes;
* tenants;
* roles e permissões;
* componentes reutilizáveis;
* adaptação da interface entre desktop e mobile.

## Sobre a demonstração

Todos os nomes, empresas, usuários, clientes, documentos e demais informações
exibidas foram preparados exclusivamente para este case.

Funcionalidades pertencentes ao roadmap não são apresentadas como módulos
entregues.
