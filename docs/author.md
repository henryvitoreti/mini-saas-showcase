## Sobre este projeto

O Mini-SaaS apresentado neste site foi desenvolvido como um projeto full stack
para aplicar e documentar decisões relacionadas a arquitetura, isolamento de
dados e reutilização de código.

Entre os principais pontos trabalhados estão:

* multi-tenancy com banco PostgreSQL isolado por empresa;
* resolução do tenant através do domínio;
* provisionamento automático de novos tenants;
* autenticação JWT vinculada ao contexto do tenant;
* permissionamento centralizado;
* arquitetura Controller → Service → Repository;
* infraestrutura genérica para buscas, filtros e paginação;
* componentização de listagens e formulários no frontend;
* responsividade e persistência de preferências da interface;
* ambiente local padronizado com Docker e Traefik.

O código completo da aplicação permanece privado. Este showcase apresenta
diagramas, documentação, demonstrações e trechos selecionados suficientes para
explicar as principais decisões da implementação.
